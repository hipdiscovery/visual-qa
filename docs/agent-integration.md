# Agent Integration

Before saying a UI task is complete:

- Do not rely only on source code inspection.
- Generate rendered screenshots.
- Inspect the screenshots.
- Verify multiple viewports.
- Correct visual problems before completion.

For HipDiscovery projects, Visual QA should be treated like automated testing: a change is incomplete until the rendered result has been checked.

Recommended approval questions:

1. Does this use the available space intentionally?
2. Is the visual hierarchy obvious within the first viewport?
3. Does it match the existing brand system?
4. Did the change introduce any regression?
